# NEXUS PC Monitor 🖥️

NEXUS PC Monitor is a real-time PC monitoring dashboard built with Python, HTML, CSS, and JavaScript. It provides a clean and modern interface for viewing important system information and performance statistics in one place.

### Features

* CPU usage, cores, and frequency monitoring
* RAM usage and memory information
* Disk usage and storage information
* Real-time upload and download speed
* Battery and charging status
* System and processor information
* Top CPU-consuming processes
* Live CPU and RAM performance graph
* Real-time clock
* Fullscreen mode
* Gaming Mode
* Dark Mode
* Responsive dashboard design
* Local Python server with JSON data API

The dashboard collects system information using Python's `psutil` library and sends live data to the browser through a local HTTP server.

### Technologies

* Python
* HTML5
* CSS3
* JavaScript
* psutil
* HTTP/JSON

Built as a personal PC monitoring and dashboard project, with the goal of creating a powerful and expandable system-monitoring experience.
